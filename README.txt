HUZAIFA'S PORTFOLIO WEBSITE — SELF-HOSTING GUIDE
================================================

Ye folder tumhari personal portfolio website hai (final version, updated CV ke saath).
Ise free me live karne ke 2 asaan tareeqe:

OPTION A — Vercel (tumhe ata hai, cine-graphix wahi par hai):
1. Is zip ko unzip karo.
2. vercel.com par jao → "Add New" → "Project" → apna GitHub connect kar ke ye folder upload karo,
   YA terminal me:  npx vercel  (folder ke andar jaa kar)
3. Deploy dabao — 1-2 minute me live link mil jayega.

OPTION B — Netlify Drop (sab se fast, account bhi free):
1. Is zip ko unzip karo.
2. app.netlify.com/drop kholo.
3. Poora folder drag-and-drop karo — foran live link mil jayega.

NOTE: index.html hamesha folder ke ROOT me rehna chahiye (assets/ folder uske saath).
Kuch change chahiye ho to Alia ko bata dena!
